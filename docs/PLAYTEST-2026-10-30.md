# Playtest record — Creamery v1.0.0 (2026-10-30)

Automated playtest of record for the sandbox build (seahawk pass on
primo is the scheduled follow-up, see BREAKAGE-LOG).

## Method

- `node tools/playtest.mjs`: the shipped wasm core in demo mode plays
  each level from `start_level` to a terminal screen. Pass = victory.
- `node tools/settings-check.mjs`: settings bridge round-trip
  (preset/flash/text), wild preset value ignored, settings reachable
  from boot without progression.
- `node tools/perf.mjs`: step budget.
- `zig test src/main.zig`: 17 tests, validation + adversarial split,
  including the per-step sync invariant (animation phase derived from
  the sample clock equals the cycle position — tolerance zero) and a
  demo-completes-every-level playthrough that also audits the book of
  record (one entry per cycle; total = sum of entries; every entry a
  full let-down under the demo policy).
- D-221 visual spot check: frames extracted from the final preview
  MP4s at viewing size and inspected — SHOULD: dark café, pump rig
  left with bellows/phase ring/vessel reading at a glance, Alma's
  abstract portrait right with posture+expression coupled to the
  cycle, legible HUD (level, face state, preset, yield/target, cycle,
  time), stroke pips + peak diamond along the bottom. First pass found
  three FAILs (lamps inside the HUD block, stroke-flash disc covering
  the rig, phase label lost on the white apron) — fixed, re-captured,
  re-inspected PASS (see BREAKAGE-LOG B-2).

## Results

- Level 1 — First Draw: VICTORY, 1395 steps, 165 ml booked (target 150).
- Level 2 — The Morning Round: VICTORY, 1960 steps, 260 ml booked (target 240).
- Level 3 — The Full Book: VICTORY, 3078 steps, 450 ml booked (target 400).
- Face visitation on the demo path: peak reached on every level
  (asserted in the core test suite).
- Sync: animation phase == cycle position at every play step, all
  levels (asserted in the core test suite).
- Settings: round-trip PASS; wild preset ignored PASS; ungated
  reachability PASS.
- Performance: 0.032 ms/step; wasm 28,131 bytes (final release gate
  run; the 17-test suite is also green in ReleaseSafe and ReleaseFast).
